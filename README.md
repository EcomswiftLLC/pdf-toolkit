# PDF Toolkit engine (Ecom Swift LLC)

Browser-only PDF tools (merge, split, extract, delete, reorder, rotate, images to PDF, PDF to JPG/PNG, compress, page numbers, watermark).
Files are processed locally in the browser and are never uploaded. Embedded on https://www.ecomswiftllc.com/pdf-tools.

Third-party code is vendored in `vendor/` (see `vendor/VERSIONS.md` and `vendor/licenses/`).
